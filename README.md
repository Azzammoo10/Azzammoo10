## About Me

I am a **Full Stack Developer** and **Cybersecurity Engineer** based in **Rabat, Morocco**, currently working as a **DLP Security Engineer Intern at AXA GBS Morocco**. I build end-to-end applications with a security-first mindset, writing **secure code** following **clean architecture** principles.

My focus spans from **full stack development** with Spring Boot, Next.js & .NET to **enterprise data protection** using Microsoft Purview & M365 DLP, combined with hands-on **penetration testing** and offensive security.
